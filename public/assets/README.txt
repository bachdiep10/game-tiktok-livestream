Đặt ảnh tượng Phật hoặc file nhạc riêng vào thư mục này, rồi ghi tên trong config.json:
  "buddhaImage": "assets/buddha.png"   (nên là PNG nền trong suốt, khung dọc)
  "musicFile":   "assets/nhac.mp3"
Chỉ dùng ảnh/nhạc bạn có quyền sử dụng (tự chụp, tự làm, mua bản quyền hoặc giấy phép miễn phí).
Để trống thì game dùng tượng Phật và nhạc thiền tự tạo sẵn.
