💒 Ăn cỗ đám cưới LIVE

Đang kết nối máy chủ...

1. Kết nối TikTok LIVE

Bạn phải đang phát LIVE thì mới kết nối được. Nhập username (không cần @).

Nhật ký sự kiện nhận từ TikTok
  • Chưa có sự kiện nào.

2. Giả lập bình luận (Test Lab)

Chương trình tiệc tự chạy vòng lặp khoảng 7 phút, MC dẫn từng màn: đón khách → tiến vào lễ đường ("chúc mừng") → trao nhẫn ("hôn đi" + tim) → cắt bánh, rót tháp ly (tim) → nâng ly ("dzô") → khai tiệc ("gà luộc", "xôi gấc", "bia") → chúc rượu từng bàn → văn nghệ ("lên bục", "ứng tuyển") → thỉnh thoảng người yêu cũ phá đám → ném hoa cưới ("bắt hoa") → chụp ảnh kỷ niệm ("chụp ảnh"). Đủ 5 lượt chia sẻ thì bắn pháo giấy, thả tim dồn dập (300 tim/phút) thì mưa tim. Đổi số giây từng màn trong config-dam-cuoi.json (phaseSeconds).

4. Thêm vào TikTok LIVE Studio / OBS

Thêm nguồn Trình duyệt (Browser source / Link) với địa chỉ:

Đang kiểm tra thư mục nhạc...

Kích thước 1080 × 1920 (khung dọc). Hoặc chạy mo-cua-so-dam-cuoi.bat để mở game trong cửa sổ Edge riêng rồi dùng "Chụp cửa sổ" (Window capture).

Muốn tự vẽ lại nền: tải ảnh nền trống, sửa xong lưu vào public/assets rồi điền tên file vào backgroundImage trong config-dam-cuoi.json.

Bấm chuột vào khung xem trước một lần để trình duyệt cho phát tiếng.
Khi đã thêm game vào LIVE Studio/OBS thì tắt ô này để không bị phát tiếng hai lần.
